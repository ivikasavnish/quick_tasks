# Resources Directory

Place your custom icon here as `icon.ico`.

If you don't have an icon, run `python generate_icon.py` to create a simple one.

## Icon Requirements

- Format: .ico (Windows icon format)
- Recommended sizes: 16x16, 32x32, 48x48, 256x256 (multi-size .ico is best)
- The icon will be used for:
  - System tray
  - Executable file
  - Taskbar (if pinned)
